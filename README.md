# PresenceFlow
Ein Anwesenheitsmanager auf Basis von Blazor Server.
*(Hinweis: Dieses Repository wird aktuell für den öffentlichen Release vorbereitet).*

## Voraussetzungen
- .NET 10 SDK

## Features
- Magic-Link Login
- SQLite oder ioBroker
- SignalR Live-Updates

## Installation & Start
1. Repository klonen.
2. dotnet ef database update
3. dotnet run
